# 🎲 Sorteio de Números Aleatórios

Projeto simples e elegante para **sortear números aleatórios** dentro de um intervalo definido pelo usuário.  
Desenvolvido com **HTML, CSS e JavaScript puro**, com foco em layout centralizado, responsividade e boa experiência do usuário.

---

## 🚀 Funcionalidades

- Definição de número **mínimo** e **máximo**
- Sorteio de números aleatórios dentro do intervalo
- Validação de campos vazios
- Validação de intervalo inválido
- Animação no momento do sorteio 🎲
- Layout centralizado e moderno
- Totalmente **responsivo** (desktop e mobile)

---

## 🖥️ Tecnologias utilizadas

- HTML5  
- CSS3 (Flexbox + Media Queries)  
- JavaScript (DOM + Math.random)

---

## 📱 Responsividade

- Desktop: inputs lado a lado e centralizados
- Mobile: inputs empilhados, mantendo usabilidade
